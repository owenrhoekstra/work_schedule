{% comment %} Banner, grid, and footer for the pattern writing form. Rendered as part of the full page on GET, and re-rendered standalone by pattern_form_preview for live HTMX updates as the user changes the week or cycle length. The id must match the hx-target in pattern_form.html. Week pagination: when cycle_weeks > 1, tabs at the top let the manager switch between weeks without vertical scrolling. Tabs stretch to fill the container width and divide equally (2 weeks = 1/2 each, 3 = 1/3 each, 4 = 1/4 each). Only the active week's panel is visible; others are hidden with display: none. Hidden inputs still submit — display: none does not affect form submission. Tab state is managed by a plain document-level click listener rather than Alpine, to sidestep the Alpine scope issues that affected the Save button earlier. Styling uses Tailwind's data-[active]: arbitrary variants — no custom CSS, no base.html changes. Retroactive: same story — no Alpine. A document-level submit interceptor opens _retroactive_confirm.html when the target week is in the past and the user hasn't yet confirmed. Confirm/Cancel are inline onclick handlers on the modal buttons, backed by window-scoped helpers. {% endcomment %}
