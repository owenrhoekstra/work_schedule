{% comment %} Banner, grid, and footer for the pattern writing form. Rendered as part of the full page on GET, and re-rendered standalone by pattern_form_preview for live HTMX updates as the user changes the week or cycle length. The id must match the hx-target in pattern_form.html. The `patternFormBody` component owns the retroactive modal flow: - Save button is type="button" and calls handleSave(). - If is_retroactive and not yet confirmed, handleSave opens the modal. - Modal confirm sets hidden `retroactive_confirmed=1` and submits. - If the server rejects a confirmed retroactive save (validation error), `retroactive_confirmed` is threaded back into context so the next Save skips the modal (no double-confirmation). The script uses `alpine:init` (fires before Alpine's deferred script runs), so registration is safe on initial page load. On HTMX swap of this partial, the script does not re-run (HTMX doesn't execute swapped scripts), and Alpine's `htmx:afterSwap` listener in base.html re-inits the swapped tree with the already-registered component. {% endcomment %}
