{% comment %} Banner, grid, and footer for the pattern writing form. Rendered as part of the full page on GET, and re-rendered standalone by pattern_form_preview for live HTMX updates as the user changes the week or cycle length. The id must match the hx-target in pattern_form.html. Week pagination: when cycle_weeks > 1, tabs at the top let the manager switch between weeks without vertical scrolling. Tabs stretch to fill the container width and divide equally. Only the active week's panel is visible; others are hidden with display: none. Hidden inputs still submit — display: none does not affect form submission. Tab state is managed by a plain document-level click listener rather than Alpine, to sidestep the Alpine scope issues that affected the Save button earlier. Form value preservation (BUG-007): cycle-length changes trigger an HTMX GET that re-renders this partial from server prefill. A small client-side cache snapshots visible time inputs before the cycle- change request fires and restores them after the swap. Confirmation flow (Session 8.5): - Cancel button opens _confirm_discard.html (unsaved-changes warning). - Save button submits; the submit interceptor picks one modal: * Retroactive and not yet confirmed → _retroactive_confirm.html. Its "Save" button is dual-duty: sets both retroactive_confirmed and saveConfirmed, then submits directly. One modal, one click. * Retroactive already confirmed this session, OR not retroactive → _confirm_save_pattern.html. Its "Save" button sets saveConfirmed and resubmits. - "Keep editing" on either modal aborts without submitting. {% endcomment %}
